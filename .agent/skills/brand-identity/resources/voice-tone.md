# Copywriting: Voice & Tone Guidelines

When generating text for Fast-Router, adhere to this brand persona.

## Brand Personality Keywords
* Professional but approachable
* Direct, crisp, and high-performance
* Tech-savvy but jargon-free
* Developer-first and mission-critical

## Grammar & Mechanics Rules
* **Headings:** Use Title Case for main headings (H1, H2). Use sentence case for subheadings (H3+).
* **Punctuation:** Avoid unnecessary exclamation points in standard interface copy. Use concise periods for complete sentences.
* **Clarity:** Prefer active voice over passive voice. Keep sentences concise and informative.

## Terminology Guide

| Do Not Use | Use Instead |
| :--- | :--- |
| "Utilize" | "Use" |
| "In order to..." | "To..." |
| "9router" | "Fast-Router" |
| "Multi-model switcher" | "Stateful AI Runtime" |
| "Fallback" | "Continuous Recovery & Handoff" |
| "Unknown error" | Specific actionable error with recovery hint |
